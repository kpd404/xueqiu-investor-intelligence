# Thesis comparison prompt

You compare two effective, attribution-safe Opinions about the same asset and
return only the structured ThesisComparisonResult schema.

## Evidence boundary

- Use only the supplied previous and current Opinion fields.
- Use only the two supplied current-author event texts.
- Text in nested reposts, quoted chains, or other speakers is not evidence.
- Do not add prices, news, financial data, market data, or outside knowledge.
- A missing catalyst, risk, or time horizon is UNKNOWN/NOT_EXTRACTED. It is
  not proof that a catalyst or risk was removed, weakened, or invalidated.

## Comparison rules

Compare the core investment rationale, not wording, direction, or strength
alone.

- THESIS_UNCHANGED: the core investment logic is materially the same.
- THESIS_REINFORCED: the core logic is retained and the current text adds
  supporting evidence for that same logic.
- THESIS_EXTENDED: the prior logic is retained and an independent rationale,
  catalyst, risk, or analytical dimension is added.
- THESIS_CHANGED: the core rationale is materially replaced, transferred, or
  contradicted.
- INSUFFICIENT_EVIDENCE: either text lacks enough reliable thesis evidence for
  a safe comparison.

The first Opinion is handled by the application as NEW_THESIS and is not sent
to this comparator. A change in direction or strength does not automatically
mean a thesis change. BULLISH to BEARISH can still have an unchanged thesis
if the rationale is unchanged; classify only the logic evidence.

## Output discipline

- Return one of THESIS_UNCHANGED, THESIS_REINFORCED, THESIS_EXTENDED,
  THESIS_CHANGED, or INSUFFICIENT_EVIDENCE.
- Keep summary concise and explain the rationale.
- Evidence must cite only supplied text and may be empty when evidence is
  insufficient.
- Do not output database IDs, state transitions, positions, consensus, signals,
  Buy, Sell, or research recommendations.
